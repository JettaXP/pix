# JettaXP / Pix 🖼️

Добро пожаловать в репозиторий **Pix**! 

Изначально этот репозиторий создавался просто как файлопомойка, но сейчас он выполняет важную функцию. Это **CDN (база ресурсов и ассетов)** для моего основного сайта — [jettaxp.github.io](https://jettaxp.github.io/), который успешно работает!

## 📂 Что здесь находится?

### 🌟 Важные файлы для сайта
Здесь хранятся тяжелые или статические ресурсы, которые подгружаются на основной сайт:
* **Изображения и иконки:** Логотипы (`jettax.png`, `Symbol.svg`), иконки соцсетей (`discord-square-color-icon.svg`, `tiktok-simplified-black-icon.svg` и др.).
* **Шрифты:** Кастомные шрифты для стилизации (`4197-font.ttf`, `Mojang.ttf`).
* **Медиа:** Музыка и видеофайлы, которые используются в оформлении сайта (например, `The Connells - 74- 75.mp3` и различные MP4/GIF).

### 🗑️ Мусор и пасхалки
Помимо полезных файлов, здесь скопилась куча мемных мини-скриптов и рофлов практически на всех существующих языках программирования. Например:
* `halal.js`, `haram.php`
* `mellstroy.py`, `sigma.go`
* `nigscript.ts`, `sus.css`, `pig.rs`, `hmm.kt`, `am am am.dart`
* ...и прочий хаос. 

Они ничего не делают, это просто щитпост и пасхалки для тех, кто решит заглянуть в репозиторий.
