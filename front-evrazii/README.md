# Фронт Евразии v2

Пиксельная стратегия на реальной карте (139 стран, 433 города). Вся игра — один файл `index.html`, открывается в браузере.

- `src/` — исходники: данные (`g_names`, `g_data`, `g_data2`), мир (`g_world`), симуляция (`g_sim`), отрисовка (`g_render`), интерфейс (`g_ui`), звук (`lib_sfx`).
- `python3 build.py` — пересобрать `index.html` из `src/`.
